# My Portfolio Project

This is my attempt to build a portfolio page in order to store all my projects in it. 

I've already tried to built some pages with React/NextJs, but the lack of time led me to ask AIs to help build my code, and that's not wrong, of course, but I barely was coding by myself and I felt like that code wasn't mine. So this time, I'll get the docs and start to learn from zero all these tools!

I'll keep updating this README to include some features I want to include in this project, describe difficulties (writing this in a secondary language is already one of them) or explain some material that I learned.
